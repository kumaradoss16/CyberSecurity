# 51. Troubleshooting Skills

This is the **highest-value skill category**.

You need to learn how to troubleshoot systematically:

```text
Identify
   ↓
Define Scope
   ↓
Gather Evidence
   ↓
Form Hypothesis
   ↓
Test
   ↓
Find Root Cause
   ↓
Fix
   ↓
Verify
   ↓
Document
```

Never make:

```text
Problem
 ↓
Random reboot
 ↓
Random configuration changes
 ↓
Reinstall everything
```

your default methodology.
